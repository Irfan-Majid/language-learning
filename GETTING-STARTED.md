## How to Run Examples

| Technology | Command |
|------------|---------|
| JavaScript | `node examples/hello.js` |
| Python | `python examples/hello.py` |
| PHP | `php examples/hello.php` |
| Go | `go run examples/hello.go` |
| Java | `javac examples/Hello.java && java -cp examples Hello` |
| TypeScript | `npx tsc examples/hello.ts && node examples/hello.js` |
| Dart/Flutter | `dart run examples/hello.dart` |
