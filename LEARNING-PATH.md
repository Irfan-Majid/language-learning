# Learning Paths — Choose Your Route

Structured routes for every audience. Pick **one path** and follow it in order.

---

## 🌱 Path 1: Complete Beginner (Never Coded Before)

**Time estimate:** 3–6 months to first job-ready project

```
Week 1–2   → languages/javascript/01-beginner/
Week 3–4   → languages/javascript/02-fundamentals/
Week 5–6   → languages/html-css/ (via javascript examples)
Week 7–8   → frameworks/react/01-beginner/
Week 9–10  → languages/sql/01-beginner/
Week 11–12 → Build a todo app (react + local storage)
Month 4+   → frameworks/express/01-beginner/ (full-stack)
```

**Why JavaScript first?** Runs in the browser instantly — no install friction. Huge job market.

**Alternative:** Start with `languages/python/01-beginner/` if you prefer data/AI career.

## Recommended Learning Order (Universal Concepts)

These concepts appear in **every** language — learn once, apply everywhere:

| # | Concept | Learn In |
|---|---------|----------|
| 1 | Variables, types, operators | Any `01-beginner/` |
| 2 | Conditionals & loops | Any `02-fundamentals/` |
| 3 | Functions / methods | Any `02-fundamentals/` |
| 4 | OOP (classes, inheritance) | Java, C#, Python, PHP |
| 5 | Collections (arrays, maps) | Any `02-fundamentals/` |
| 6 | Error handling | Any `03-intermediate/` |
| 7 | Async / concurrency | Any `03-intermediate/` |
| 8 | HTTP & REST APIs | Any framework `02-fundamentals/` |
| 9 | Databases & ORM | `languages/sql` + any backend |
| 10 | Testing | Any `06-testing/` |
| 11 | Deployment | `devops/docker/` |
| 12 | Security basics | Any `04-advanced/` |
