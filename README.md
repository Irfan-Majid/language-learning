## Repository Structure

```
language-learning/
├── CHAT-CONTEXT.md          # Saved user request (reference)
├── README.md                # This file — master index
├── LEARNING-PATH.md         # Step-by-step learning routes
├── STACK-COMPARISON.md      # Side-by-side stack comparison
│
├── languages/               # Core programming languages
├── frameworks/              # Web & backend frameworks
├── mobile/                  # Mobile development
├── databases/               # SQL & NoSQL
├── testing/                 # Testing tools & QA
├── devops/                  # DevOps & infrastructure
├── tools/                   # Git, IDEs, package managers
├── web/                     # HTML & CSS foundations
├── security/                # Cybersecurity, ethical hacking, AppSec, QA
├── problem-solving/         # DSA, debugging, system design, interviews
├── essentials/              # Auth, REST, GraphQL, CI/CD, Agile, other
├── career/                  # Layoff prep, future-proof skills, 90-day plan
├── ai-era/                  # AI skills that keep you employable
└── data-ai/                 # CampusX, GenAI, ML, DS, BI, RAG, math
```

### Every Technology Folder Contains

```
<technology>/
├── README.md                # Overview, use cases, when to choose
├── resources.md             # Official docs + web links
├── 01-beginner/             # Zero to first program
├── 02-fundamentals/         # Core syntax, OOP, patterns
├── 03-intermediate/         # APIs, async, packages
├── 04-advanced/             # Performance, architecture
├── 05-expert/               # Internals, contributions
├── 06-testing/              # Unit, integration, E2E for this stack
├── 07-project-management/   # Estimation, risks, team workflow
├── 08-stack-switching/      # Migrate from/to other stacks
└── examples/                # Runnable code samples
```
