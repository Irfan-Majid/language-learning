# AI Ethics & Responsibility — Senior Credibility

Short module. Long-term career trust.

---

## Why This Matters for Your Career

Companies fear AI lawsuits, privacy breaches, and brand damage. Developers who understand ethics get trusted with **production AI** — not just experiments.

---

## Core Principles

| Principle | Practice |
|-----------|----------|
| **Privacy** | Don't send customer PII to APIs without consent |
| **Transparency** | Tell users when AI generated content |
| **Human oversight** | Human approves high-stakes decisions |
| **Bias awareness** | Test outputs across diverse inputs |
| **Security** | Prompt injection, data leakage prevention |
| **Honesty** | Don't claim AI is "always right" |

---

## Data Rules

| Never send to external LLM | OK with care |
|----------------------------|--------------|
| Passwords, API keys | Anonymized logs |
| Full customer records | Aggregated metrics |
| HIPAA/PCI data without BAA | Public documentation |
| Unredacted internal secrets | Synthetic test data |

---

## Disclosure Examples

**Good UI copy:**
> "This summary was generated by AI. Verify important details."

**Good README:**
> "Uses OpenAI API. User messages are sent to OpenAI per their privacy policy."

---

## When to Say No at Work

| Request | Response |
|---------|----------|
| "Send all customer emails to ChatGPT" | Propose redaction pipeline |
| "Fully automate firing decisions" | Require human review |
| "Skip testing, AI is smart enough" | Document risks, request QA time |
| "Hide that we use AI" | Advocate transparency |

**Saying no professionally = senior behavior.**
