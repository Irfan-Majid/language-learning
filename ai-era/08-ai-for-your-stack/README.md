# AI for Your Stack — Quick Reference

Apply AI skills to the language you already know.

---

## JavaScript / TypeScript

| Use | Tool |
|-----|------|
| Daily coding | Cursor, Copilot |
| LLM in app | OpenAI npm package, Vercel AI SDK |
| Frontend chat UI | React + streaming responses |
| Agents | LangChain.js |

**Folders:** `languages/typescript/`, `frameworks/nextjs/`

---

## Strategy

1. **Don't switch language just for AI** — add AI to your current stack first
2. **If starting fresh for AI career** → Python + FastAPI + `ai-era/`
3. **Enterprise job** → Java Spring AI or C# Semantic Kernel
