# Layoff Preparedness — Be Ready Before It Happens

**Reality:** Tech layoffs happen because of funding, mergers, over-hiring, and business pivots — not always because you failed. Preparation turns a crisis into a transition.

---

## The 24-Hour Checklist (If You Were Just Laid Off)

Do these **in order** on day 1:

| # | Action | Why |
|---|--------|-----|
| 1 | **Breathe.** This is survivable. Thousands recover every month. | Panic leads to bad decisions |
| 2 | File for unemployment **immediately** (if available in your country) | Benefits have waiting periods |
| 3 | Review severance letter — don't sign same day if possible | You may have negotiation room |
| 4 | Export contacts from work email/Slack (allowed ones only) | Network is your fastest job source |
| 5 | Ask managers for LinkedIn recommendations **now** | Easier while memory is fresh |
| 6 | Update LinkedIn: open to work (recruiters use this) | Visibility |
| 7 | Message 10 trusted contacts privately — not public panic | Referrals beat job boards |
| 8 | Do NOT badmouth former employer publicly | Recruiters notice |
| 9 | List expenses — cut non-essentials for 90 days | Extend runway |
| 10 | Start [90-DAY-CAREER-SECURITY-PLAN](../90-DAY-CAREER-SECURITY-PLAN.md) at Week 1 | Structure reduces anxiety |

## What to Keep From Work (Legally)

| OK (usually) | NOT OK |
|--------------|--------|
| Descriptions of what you built (your words) | Source code, unless open source |
| Architecture diagrams you drew | Customer data, passwords, API keys |
| Metrics you achieved ("reduced latency 40%") | Proprietary algorithms |
| Skills you gained | Internal documents marked confidential |
| Public projects you contributed to | Designs under NDA |

**Rule:** If unsure, describe the **problem and your role**, not proprietary details.

## Signs a Layoff Might Be Coming

Not definitive — but worth preparing if you see multiple:

- Hiring freeze announced
- Multiple peer layoffs in industry
- Budget cuts, project cancellations
- Leadership churn (new CEO, restructuring)
- Your projects deprioritized with no new work
- Access removed gradually (tools, meetings)

**If you see 3+:** Accelerate [90-day plan](../90-DAY-CAREER-SECURITY-PLAN.md). Update resume. Activate network quietly.

## Emotional Health

Layoff fear is **valid**. Protect your mental health:

| Do | Don't |
|----|-------|
| Talk to trusted friends/family | Doom-scroll layoff news daily |
| Exercise, sleep, routine | Isolate for weeks |
| Focus on what you control | Compare yourself to influencers |
| Set 1 small win per day | Decide "tech is dead" from headlines |

## Recovery Timeline (Typical)

| Phase | Duration | What happens |
|-------|----------|--------------|
| Shock | 1–2 weeks | Processing, admin tasks |
| Active search | 4–12 weeks | Applications, interviews |
| Offers | Week 6–16+ | Depends on market, location, seniority |
| Re-employed | Month 2–6 | Most developers with solid skills |

**Factors that speed recovery:** network referrals, portfolio, multiple stack skills, AI fluency, realistic salary expectations.
