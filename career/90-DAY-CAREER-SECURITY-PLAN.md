# 90-Day Career Security Plan

**For:** Developers worried about AI, layoffs, and the future  
**Time:** ~1 hour/day (adjust to your life)  
**Goal:** Be significantly harder to lay off — and faster to rehire if it happens

---

## How to Use This Plan

- Start **today**, even if you feel safe
- Check off items weekly — progress reduces anxiety
- Skipping is OK; **consistency** beats perfection
- Pair with [02-future-proof-skills/](./02-future-proof-skills/) and [../ai-era/](../ai-era/)

## Minimum Viable Plan (If You Only Have 15 Min/Day)

If 1 hour is too much, do **only these 5 things** for 90 days:

1. **Use AI daily** at real work (`ai-era/02-prompt-engineering/`)
2. **1 GitHub commit/week** on portfolio
3. **1 LinkedIn touch/week** (post, comment, or connect)
4. **Save money** — any amount toward 6-month fund
5. **Read 1 career doc/week** from this folder
