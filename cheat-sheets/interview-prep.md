# Interview Prep Cheat Sheet

## Before the interview
- [ ] Research company + role
- [ ] Prepare 3 questions to ask them
- [ ] Test webcam/mic if remote
- [ ] Have IDE or paper ready for coding

## STAR method (behavioral)
- **S**ituation - context in 1 sentence
- **T**ask - your responsibility
- **A**ction - what YOU did (specific steps)
- **R**esult - measurable outcome

## Coding interview flow
1. **Clarify** - ask about input, edge cases, constraints
2. **Example** - walk through small input by hand
3. **Approach** - explain brute force, then optimize
4. **Code** - clean, talk while writing
5. **Test** - run your example + edge cases
6. **Complexity** - state time and space Big O

## Common patterns
| Pattern | When |
|---------|------|
| Two pointers | Sorted array pairs |
| Hash map | O(1) lookups, counting |
| BFS/DFS | Trees, graphs |
| Sliding window | Subarray problems |
| Binary search | Sorted data |
