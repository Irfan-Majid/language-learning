# Data, AI & Analytics Learning Hub

Complete path from **mathematics** → **data analysis** → **data science** → **ML** → **AI engineering** → **RAG apps** → **BI**.

Includes **CampusX** curriculum alignment (Generative AI Series, 100 Days ML, LangChain playlists).

---

## Learning Roadmap (Recommended Order)

```
Mathematics (foundation)
    ↓
Data Analysis (Excel, SQL, pandas)
    ↓
Data Science (stats, visualization, EDA)
    ↓
Machine Learning (models, training, evaluation)
    ↓
AI Engineering (LLMs, APIs, production)
    ↓
Generative AI Series / CampusX (LangChain, agents)
    ↓
RAG Applications (enterprise chatbots, doc Q&A)
    ↓
Business Intelligence (dashboards, reporting)
```

**Career tie-in:** [career/04-resilient-paths/](../career/04-resilient-paths/) Path 3 — AI Application Engineer
