# Beginner Guide — AI Engineering

**Audience:** Developers or analysts new to AI engineering  
**Time:** 2–3 weeks

---

## What Is an AI Engineer?

Someone who **builds products** using AI (chatbots, RAG apps, agents) — not someone who only trains models from scratch.

---

## Week 1: Setup & First API

| Day | Task |
|-----|------|
| 1 | Install Python 3.11+, VS Code |
| 2 | `pip install openai fastapi python-dotenv` |
| 3 | Run [ai-era/examples/openai_basic.py](../../ai-era/examples/openai_basic.py) |
| 4 | Read [ai-era/01-understanding-ai/](../../ai-era/01-understanding-ai/) |
| 5 | Read [ai-era/02-prompt-engineering/](../../ai-era/02-prompt-engineering/) |
| 6 | Build: script that summarizes any text file |
| 7 | Push to GitHub |
