# AI Engineering

**AI Engineer** = builds production systems using LLMs, RAG, agents, and ML — not just trains models in a lab.

One of the **fastest-growing job titles** in 2025–2026.

---

## What Is AI Engineering?

| ML Engineer (traditional) | AI Engineer (2026) |
|---------------------------|-------------------|
| Train custom models | Integrate foundation models (GPT, Claude, Llama) |
| Feature engineering | Prompt engineering + RAG |
| Batch predictions | Real-time APIs, chatbots, agents |
| Jupyter notebooks | FastAPI, Docker, monitoring |
