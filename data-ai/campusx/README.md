## CampusX Curriculum — Two Sides of AI

CampusX teaches Generative AI from **two perspectives**:

| Side | Who | Topics |
|------|-----|--------|
| **Builder** | Research-oriented, deep ML | Transformers, foundation models, training |
| **User** | Application engineers (most jobs) | LangChain, RAG, agents, APIs, deployment |

**For career security → focus User side first**, then deepen Builder side.

## Suggested CampusX Learning Order

### Path A: Complete Beginner → AI Engineer (6–9 months)

```
1. 100 Days of Machine Learning (CampusX YouTube)
   → data-ai/machine-learning/

2. Mathematics for ML (as needed)
   → data-ai/mathematics/

3. GenAI Roadmap (CampusX)
   → data-ai/campusx/generative-ai-series/

4. Generative AI using LangChain (CampusX)
   → data-ai/rag-applications/

5. Agentic AI using LangGraph
   → data-ai/ai-engineering/

6. Portfolio + career plan
   → career/07-portfolio/ + career/90-DAY-CAREER-SECURITY-PLAN.md
```

### Path B: Already a Developer → GenAI Fast Track (2–3 months)

```
1. GenAI Roadmap (CampusX) — 1 video overview
2. languages/python/02-fundamentals/

4. data-ai/rag-applications/ — build capstone
```
