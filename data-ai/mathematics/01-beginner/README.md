# Beginner Guide — Mathematics for ML/AI

You don't need to be a mathematician. You need **enough math to not feel lost**.

---

## Start With Statistics (Not Calculus)

Statistics is used **every day** in data analysis, ML, and A/B tests.

```bash
python data-ai/examples/stats_basics.py
```

---

## Week 1 Plan

| Day | Topic |
|-----|-------|
| 1 | Mean, median, mode — run `stats_basics.py` |
| 2 | Variance, standard deviation |
| 3 | Khan Academy: basic probability |
| 4 | Correlation (does X relate to Y?) |
| 5 | StatQuest YouTube: "P-values" |
| 6 | StatQuest: "Standard deviation" |
| 7 | Review — explain mean vs median to a friend |
