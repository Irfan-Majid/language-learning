# Agile, Scrum & Project Basics

How dev teams **plan and deliver** work — essential for devs and PMs.

---

## Agile Values

- Individuals over processes
- Working software over documentation
- Customer collaboration over contracts
- Responding to change over plans

---

## Scrum (Most Common)

| Ceremony | Frequency | Purpose |
|----------|-----------|---------|
| **Sprint** | 1–4 weeks | Time box for work |
| **Daily standup** | 15 min daily | Blockers, plan |
| **Sprint planning** | Start of sprint | Pick stories |
| **Retrospective** | End of sprint | Improve process |
| **Review/demo** | End of sprint | Show stakeholders |

---

## Key Terms

| Term | Meaning |
|------|---------|
| User story | Feature from user perspective |
| Backlog | Prioritized list of work |
| Story points | Effort estimate (relative) |
| Definition of Done | Checklist before "complete" |
| Kanban | Visual board, continuous flow |

---

## For Developers

- Break tasks < 2 days
- Update ticket status daily
- Ask early when blocked
- Demo working software
