## Why Contribute

| Benefit | How |
|---------|-----|
| Portfolio | Public PRs on GitHub |
| Learning | Read production codebases |
| Network | Meet maintainers |
| Interviews | "I contributed to X" |

---

## First Contribution Path

```
1. Find project you USE (React, FastAPI, docs)
2. Read CONTRIBUTING.md
3. Fix typo in docs (easiest first PR)
4. "good first issue" label
5. Small bug fix with test
6. Larger feature (discuss in issue first)
```

---

## PR Checklist

- [ ] One logical change per PR
- [ ] Tests pass
- [ ] Follow project code style
- [ ] Clear PR description
- [ ] Link related issue
