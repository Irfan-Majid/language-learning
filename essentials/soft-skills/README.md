# Soft Skills for Developers

Code gets you hired — **soft skills** get you promoted and keep you employed.

---

## Core Soft Skills

| Skill | Practice |
|-------|----------|
| **Communication** | Explain tech to non-tech clearly |
| **Listening** | Understand requirements before coding |
| **Teamwork** | Code review with kindness |
| **Time management** | Estimate honestly, say no when overloaded |
| **Adaptability** | Learn new stack when project needs it |
| **Problem solving** | [problem-solving/](../../problem-solving/) |
| **Empathy** | Users and teammates are human |

---

## Code Review Etiquette

| Do | Don't |
|----|-------|
| Suggest, don't demand | "This is wrong" without why |
| Praise good code | Only negative comments |
| Ask questions | Assume bad intent |
| Link to docs | Sarcasm |

---

## With Stakeholders

- Translate "it'll take 2 weeks" into business impact
- Say "I don't know, I'll find out" when true
- Demo early, demo often
