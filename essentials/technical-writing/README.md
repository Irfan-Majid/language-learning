# Technical Writing & Documentation

Good docs = employability + team respect.

---

## What to Write

| Document | Audience |
|----------|----------|
| README | New developers on project |
| API docs | Frontend / external devs |
| ADR | Architecture decisions |
| Runbook | On-call engineers |
| CHANGELOG | Users, team |

---

## README Template

```markdown
# Project Name
One sentence what it does.

## Setup
\`\`\`bash
npm install && npm run dev
\`\`\`

## Environment variables
| Var | Description |
|-----|-------------|

## API endpoints
| Method | Path | Description |

## Tests
\`\`\`bash
npm test
\`\`\`
```

---

## Tips

- Write for someone with zero context
- Code blocks with language tags
- Screenshots for UI
- Keep updated when code changes
