## Essential Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+`` ` | Toggle terminal |
| `F5` | Start debugger |
| `F9` | Breakpoint |
| `Ctrl+P` | Quick open file |
| `Ctrl+Shift+P` | Command palette |
| `Alt+Up/Down` | Move line |

---

## Debugger Setup

1. Open JS/Python file
2. Set breakpoint (click left of line number)
3. F5 → select Node or Python
4. Step over (F10), into (F11)
