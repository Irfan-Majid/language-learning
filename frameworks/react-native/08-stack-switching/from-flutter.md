# Flutter → React Native

| Flutter | React Native |
|---------|--------------|
| Dart | JavaScript / TypeScript |
| Widget tree | Component tree |
| `setState()` | `useState()` |
| Material / Cupertino widgets | Native platform components |
| Skia rendering | Bridge to native UI |
| `pubspec.yaml` | `package.json` |
| Hot reload | Fast Refresh |
| One UI everywhere | Platform-specific tweaks |

**Why switch:** Your team is JS-heavy, or you need deeper native module ecosystem.

**What transfers:** Component state, navigation concepts, mobile debugging mindset.

**Challenge:** Lose pixel-perfect cross-platform consistency — test on both iOS and Android.
