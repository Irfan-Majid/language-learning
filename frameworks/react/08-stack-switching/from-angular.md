# Angular → React

| Angular | React |
|---------|-------|
| Full framework | Library + ecosystem |
| TypeScript required | TypeScript optional |
| `NgModule` | No modules (components only) |
| `*ngIf`, `*ngFor` | `{condition &&}`, `.map()` |
| RxJS everywhere | useState + fetch (or React Query) |
| `ng generate` | Create files manually or Vite |
| Services + DI | Hooks, context, custom hooks |
| Built-in routing | React Router |

**Why switch:** More jobs in startups, larger npm ecosystem, often faster to prototype.

**Challenge:** You lose built-in structure — add React Router, state library, and conventions yourself.
