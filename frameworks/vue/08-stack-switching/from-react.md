# React → Vue

| React | Vue 3 |
|-------|-------|
| `useState(0)` | `ref(0)` |
| `useEffect` | `watch`, `onMounted` |
| `onClick` | `@click` |
| JSX | `<template>` |
| `className` | `class` |
| Props as function args | `defineProps()` |
| Context API | `provide` / `inject` |
| Redux / Zustand | Pinia |

**Why switch:** Vue is easier to learn, great docs, strong in Asia/Europe.

**What transfers:** Component thinking, props down / events up, SPA architecture.

**30-day plan:** Week 1 Vue basics, Week 2 Pinia + router, Week 3 rebuild a React component in Vue, Week 4 small app.
