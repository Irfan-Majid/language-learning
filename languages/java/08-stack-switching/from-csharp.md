# C# → Java

| C# | Java |
|----|------|
| `.NET` / CLR | JVM |
| `namespace` | `package` |
| `var` | `var` (Java 10+) |
| `async/await` | `CompletableFuture`, virtual threads |
| LINQ | Streams API |
| Properties `{ get; set; }` | Getters/setters or records |
| ASP.NET Core | Spring Boot |
| Entity Framework | JPA / Hibernate |
| NuGet | Maven / Gradle |

**Why switch:** Java = largest enterprise job market globally (banks, outsourcing, Android backend).

**What transfers:** OOP, interfaces, generics, enterprise patterns — very similar mental model.
