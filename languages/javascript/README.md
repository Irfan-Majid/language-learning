# JavaScript

> **Category:** Programming Language  
> **Difficulty:** Easy to start, deep to master  
> **Global use:** #1 language on the web — frontend, backend (Node.js), mobile (React Native), desktop (Electron)

---

## What Is JavaScript?

JavaScript (JS) is the programming language of the web. It runs in every browser and, via **Node.js**, on servers worldwide. Originally created in 10 days in 1995, it now powers Netflix, Facebook, Google, Amazon, and millions of websites.

---

## When to Choose JavaScript

| Choose it when… | Avoid it when… |
|-----------------|----------------|
| Building websites or web apps | Heavy CPU computation (use Rust, Go, C++) |
| You want one language for frontend + backend | Hard real-time systems |
| Large job market matters | Strict enterprise typing needed (use TypeScript) |
| Real-time apps (chat, games) | Mobile performance is critical alone (consider native) |

---

## Who Uses JavaScript?

Google, Meta, Netflix, Uber, Airbnb, Spotify, LinkedIn, and virtually every web startup.
