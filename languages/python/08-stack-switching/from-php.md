# PHP → Python

| PHP | Python |
|-----|--------|
| `<?php ?>` | No tags — `.py` files |
| `$variable` | `variable` |
| `echo` | `print()` |
| `array()` / `[]` | `list` / `dict` |
| `->` method call | `.` method call |
| Laravel | Django / FastAPI |
| Composer | pip + `requirements.txt` |
| `null` | `None` |
| Apache/Nginx + PHP-FPM | Uvicorn/Gunicorn |

**Why switch:** Python dominates AI/ML, data science, and modern APIs.

**Map your skills:** Laravel MVC → Django MVC. Eloquent → Django ORM or SQLAlchemy.

**30-day plan:** Week 1 Python syntax, Week 2 FastAPI, Week 3 Django or data-ai/, Week 4 port one PHP feature to Python.
