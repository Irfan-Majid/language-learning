# Beginner Guide - Ruby

**Time:** 2 weeks

## Step 1: Install
- Windows: RubyInstaller | Mac: pre-installed or `brew install ruby`

## Step 2: Run example
```bash
ruby examples/hello.rb
```

## Step 3: Core concepts
```ruby
name = "Ruby"
[1,2,3].each { |n| puts n * 2 }
def greet(name); "Hello, #{name}!"; end
{ name: "Alice", age: 30 }  # hash
```
