## Path 1: Beginner → Can Solve Basic Problems (8 weeks)

| Week | Module | Practice |
|------|--------|----------|
| 1–2 | [logical-thinking/01-beginner/](./logical-thinking/01-beginner/) | 10 word problems on paper |
| 3–4 | [debugging/02-fundamentals/](./debugging/02-fundamentals/) | Break 5 bugs in your code |
| 5–6 | [algorithms-data-structures/02-fundamentals/](./algorithms-data-structures/02-fundamentals/) | Arrays, strings, hash maps |
| 7–8 | [interview-coding/02-fundamentals/](./interview-coding/02-fundamentals/) | 20 Easy LeetCode |
