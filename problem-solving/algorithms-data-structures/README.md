# Algorithms & Data Structures (DSA)

Foundation for **efficient code**, **interviews**, and **understanding how software scales**.

---

## Big O Notation (Complexity)

| Notation | Name | Example |
|----------|------|---------|
| O(1) | Constant | Hash map lookup |
| O(log n) | Logarithmic | Binary search |
| O(n) | Linear | Loop through array |
| O(n log n) | Linearithmic | Good sorting |
| O(n²) | Quadratic | Nested loops |
| O(2ⁿ) | Exponential | Avoid in production |

## Core Data Structures

| Structure | Use case |
|-----------|----------|
| **Array** | Ordered list, index access |
| **Hash Map / Object** | Fast lookup by key |
| **Set** | Unique values |
| **Stack** | LIFO — undo, parsing |
| **Queue** | FIFO — BFS, tasks |
| **Linked List** | Insert/delete at head |
| **Tree** | Hierarchy, BST search |
| **Graph** | Networks, social, maps |
| **Heap** | Priority queue, top K |
