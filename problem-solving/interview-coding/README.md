# Interview Coding (LeetCode Style)

Prepare for **technical interviews** — coding rounds at most companies.

---

## Interview Types

| Round | Format | Prep |
|-------|--------|------|
| Phone screen | 1–2 Easy/Medium | LeetCode Easy |
| Onsite coding | 2–4 Medium | Patterns + Medium |
| Take-home | Real project | Portfolio, clean code |
| System design | Senior only | [system-design/](../system-design/) |

---

## Top Patterns (NeetCode 150)

| Pattern | Example problems |
|---------|------------------|
| Two pointers | Two sum sorted, palindrome |
| Sliding window | Max subarray, longest substring |
| Hash map | Two sum, group anagrams |
| Binary search | Search rotated array |
| BFS/DFS | Islands, tree traversal |
| Dynamic programming | Climbing stairs, coin change |
| Backtracking | Permutations, subsets |

---

## How to Solve in Interview (45 min)

| Time | Step |
|------|------|
| 5 min | Clarify, examples, edge cases |
| 5 min | Brute force + complexity |
| 20 min | Optimize, code |
| 10 min | Test with examples |
| 5 min | Discuss time/space complexity |

**Talk out loud** — silence fails interviews.
