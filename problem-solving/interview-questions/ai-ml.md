# AI / ML Interview Questions

## Mid-Level

1. Supervised vs unsupervised vs reinforcement learning?
2. Bias-variance tradeoff?
3. How do you evaluate a classification model?
4. What is overfitting and how do you prevent it?
5. Explain train/validation/test split.
6. What is an embedding?
7. RAG vs fine-tuning - when to use each?
8. How do you estimate LLM API costs?

## Senior

1. Design a document Q&A system for enterprise PDFs.
2. MLOps: model versioning, monitoring, rollback.
3. Handle hallucinations in production LLM apps.
4. Feature store architecture.
5. Responsible AI: bias detection and mitigation.
6. Agent systems: tool use, planning, failure modes.
7. Vector database selection criteria.
8. A/B testing ML models in production.
