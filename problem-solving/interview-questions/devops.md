# DevOps & Cloud Interview Questions

## Mid-Level

1. What is the difference between Docker and Kubernetes?
2. Explain CI/CD pipeline stages.
3. Blue-green vs canary deployments?
4. What is Infrastructure as Code? Tools you know?
5. How do you store secrets in production?
6. Explain horizontal vs vertical scaling.
7. What is a health check / readiness probe?
8. Basic AWS: EC2, S3, RDS, Lambda - what is each?

## Senior

1. Design CI/CD for a microservices monorepo.
2. GitOps workflow with ArgoCD or Flux.
3. Multi-cloud strategy tradeoffs.
4. SLO/SLI/SLA definitions and error budgets.
5. Incident response process you have run.
6. Terraform state management at team scale.
7. Kubernetes networking (CNI, Ingress, Service mesh).
8. FinOps: how do you control cloud spend?
