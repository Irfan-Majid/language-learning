# JavaScript Interview Questions

## Junior

1. What is the difference between `let`, `const`, and `var`?
2. Explain `==` vs `===`.
3. What is a closure? Give an example.
4. How does `map`, `filter`, and `reduce` work?
5. What is the event loop?
6. Implement FizzBuzz.
7. Reverse a string without built-in `reverse()`.
8. Find the largest number in an array.

## Mid-Level

1. Explain prototypal inheritance.
2. What is hoisting?
3. Implement `Promise.all` from scratch.
4. Debounce vs throttle - when to use each?
5. How does `this` binding work in arrow vs regular functions?
6. Explain CORS and how to handle it.
7. Implement a simple `fetch` wrapper with retry logic.
8. What are memory leaks in JavaScript and how to avoid them?

## Senior

1. Design a client-side caching layer for API responses.
2. Micro-frontend architecture tradeoffs.
3. How would you optimize a React app with 10k list items?
4. Explain V8 optimization and deoptimization.
5. Event-driven architecture in Node.js at scale.
