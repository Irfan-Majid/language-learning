# Python Interview Questions

## Junior

1. List vs tuple vs set vs dict - when to use each?
2. What is a list comprehension?
3. Explain `*args` and `**kwargs`.
4. What is the difference between a module and a package?
5. How do you handle exceptions?
6. Implement FizzBuzz.
7. Count word frequency in a string.
8. Read a CSV file and print the sum of a numeric column.

## Mid-Level

1. Explain decorators with an example.
2. What is the GIL and how does it affect threading?
3. `asyncio` vs `threading` vs `multiprocessing`.
4. How does pytest fixture scope work?
5. Design a simple REST API with FastAPI.
6. Explain context managers (`with` statement).
7. Type hints - why use them?
8. How would you structure a medium Python project?

## Senior

1. Design a data pipeline with error handling and retries.
2. When to use Celery vs asyncio for background jobs?
3. Packaging and distributing internal Python libraries.
4. Performance profiling workflow in production.
5. Security checklist for Python web APIs.
