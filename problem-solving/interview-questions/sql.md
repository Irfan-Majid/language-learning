# SQL & Database Interview Questions

## Junior

1. SELECT, INSERT, UPDATE, DELETE - explain each.
2. What is a PRIMARY KEY vs FOREIGN KEY?
3. INNER JOIN vs LEFT JOIN?
4. What is an index and why use one?
5. Write a query to find duplicate emails in a `users` table.
6. Normalize a simple orders schema to 3NF.

## Mid-Level

1. Explain ACID properties.
2. What are transaction isolation levels?
3. How do you optimize a slow query? (EXPLAIN)
4. When to use PostgreSQL vs MongoDB?
5. Design schema for a social media app (users, posts, likes).
6. What is connection pooling?
7. How do migrations work in production?
8. Explain Redis use cases alongside a SQL database.

## Senior

1. Design a multi-tenant SaaS database schema.
2. Sharding vs replication strategies.
3. Event sourcing vs CRUD - tradeoffs.
4. Zero-downtime migration approach.
5. CAP theorem in practical terms.
