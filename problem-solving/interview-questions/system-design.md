# System Design Interview Questions

## Mid-Level

1. Design a URL shortener (like bit.ly).
2. Design a rate limiter.
3. Design a notification system (email + push).
4. Design a chat application.
5. Design a file upload service.
6. Explain load balancing strategies.
7. Caching layers - where and what to cache?
8. SQL vs NoSQL for a new startup - how do you decide?

## Senior

1. Design Twitter/X timeline at scale.
2. Design Uber ride matching.
3. Design a video streaming platform.
4. Multi-region active-active architecture.
5. Event-driven microservices vs monolith migration.
6. Observability stack design (logs, metrics, traces).
7. Disaster recovery RPO/RTO planning.
8. Cost optimization for a cloud-native system.

## Framework for Answers

1. **Requirements** - functional + non-functional (scale, latency)
2. **Estimates** - users, QPS, storage
3. **API design** - main endpoints
4. **Data model** - tables/collections
5. **High-level diagram** - clients, LB, services, DB, cache
6. **Bottlenecks** - identify and mitigate
7. **Tradeoffs** - what you chose and why
