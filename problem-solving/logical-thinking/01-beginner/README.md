# Beginner Guide — Logical Thinking

**Week 1 — no coding required**

---

## Exercise 1: Decompose

**Task:** "Make a sandwich" → list 10 steps in order.  
**Task:** "User registers on website" → list steps (UI, validation, DB, email).

---

## Exercise 2: Input / Output

For each problem write:
- **Input:** what goes in
- **Output:** what should come out
- **Rules:** any constraints

Example: Find largest number in a list  
- Input: `[3, 1, 9, 2]`  
- Output: `9`

---

## Exercise 3: Edge cases

For "average of numbers" list:
- Empty list → ?
- One number → ?
- Negative numbers → ?

---

## Daily habit

Before opening IDE for any task, spend **5 minutes** writing steps on paper.
