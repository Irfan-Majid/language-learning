# Security & QA — Learning Paths

---

## Path 1: Developer → Application Security (3 months)

```
Month 1:  security/cybersecurity/01-beginner/
          security/application-security/02-fundamentals/ (OWASP Top 10)
Month 2:  languages/javascript/04-advanced/ (security section)
          frameworks/express/ + secure API patterns
Month 3:  security/database-security/
          security/devsecops/01-beginner/
Portfolio: Fix OWASP issues in a demo app
```

---

## Path 2: QA → Security QA / Tester (2–3 months)

```
Week 1–2:  testing/jest/ or testing/cypress/ (your stack)
Week 3–4:  security/security-qa/01-beginner/
Week 5–6:  security/application-security/ (test cases for OWASP)
Week 7–8:  security/cybersecurity/02-fundamentals/
Week 9–12: Build test plan + automate security checks in CI
```

---

## Path 3: Ethical Hacker / Pen Tester (6–12 months)

**Prerequisites:** Networking basics, Linux, one programming language (Python recommended)

```
Phase 1 (2 mo):  security/cybersecurity/
                 security/network-security/
                 security/pc-security/ (Linux CLI)
Phase 2 (2 mo):  security/ethical-hacking/02-fundamentals/
                 TryHackMe / HackTheBox (legal labs)
Phase 3 (2 mo):  security/application-security/
                 security/mobile-security/
Phase 4 (2 mo):  security/cloud-security/
                 Cert prep: CEH, OSCP, or Security+
Phase 5:         Bug bounty (HackerOne) — only in-scope targets
```

## Daily Study (1 hour)

| Min | Activity |
|-----|----------|
| 20 | Read one security module section |
| 30 | Lab (TryHackMe, secure code exercise) |
| 10 | Write one security note in your own words |

---

## Legal & Ethical Rules

1. Only test systems you **own** or have **written permission** to test
2. Bug bounty = follow program rules exactly
3. Never access real user data without authorization
4. Document findings responsibly (responsible disclosure)
