# Security, Cybersecurity & QA Hub

Complete learning path for **cybersecurity**, **ethical hacking**, **application/device/PC/phone security**, **database security & optimization**, **security testing**, and **software QA**.

> **Legal notice:** Ethical hacking content is for **authorized testing only** — your own systems, labs, bug bounty programs with permission, or CTF challenges. Unauthorized access is illegal.

## Learning Roadmap

```
Cybersecurity fundamentals
    ↓
PC security + Device security (your own machines)
    ↓
Application security + Software security (code you write)
    ↓
Database security + optimization
    ↓
Mobile security (phone/tablet)
    ↓
Network security + Cloud security
    ↓
Ethical hacking (authorized labs only)
    ↓
Security QA + Software testing QA
    ↓
DevSecOps (security in CI/CD)
```

**Full route:** [LEARNING-PATH.md](./LEARNING-PATH.md)
