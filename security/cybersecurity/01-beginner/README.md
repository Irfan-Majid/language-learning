# Beginner Guide — Cybersecurity

**Time:** 1 week | **No coding required to start**

---

## Day 1–2: Mindset & Basics

- Learn **CIA triad**: Confidentiality, Integrity, Availability
- Use a **password manager** (Bitwarden, 1Password free tier)
- Enable **2FA** on: email, GitHub, Google, banking
- Update your OS and phone **today**

---

## Day 3–4: Recognize Threats

| Threat | Red flags |
|--------|-----------|
| Phishing | Urgent tone, wrong URL, spelling errors |
| Malware | Unexpected popups, slow PC, unknown processes |
| Scams | "You've won", crypto giveaways, fake support |

**Rule:** When in doubt, don't click. Go to site directly by typing URL.

---

## Day 5–7: Your First Security Habits

- [ ] Password manager installed
- [ ] 2FA on top 5 accounts
- [ ] PC screen lock (5 min timeout)
- [ ] Backup one important folder
- [ ] Read [pc-security/01-beginner/](../pc-security/01-beginner/)
