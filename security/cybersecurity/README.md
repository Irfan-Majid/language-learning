# Cybersecurity

Foundation of all security learning — threats, defenses, careers, and laws.

---

## CIA Triad (Core Model)

| Principle | Meaning | Example |
|-----------|---------|---------|
| **Confidentiality** | Only authorized access | Encryption, access control |
| **Integrity** | Data not tampered | Hashing, digital signatures |
| **Availability** | Systems stay up | Backups, DDoS protection |

---

## Common Threats

| Threat | Description |
|--------|-------------|
| Malware | Virus, ransomware, trojan |
| Phishing | Fake emails/sites steal credentials |
| Social engineering | Manipulate people, not code |
| DDoS | Overwhelm servers with traffic |
| Insider threat | Malicious or careless employees |
| Supply chain | Compromised dependencies |
| AI attacks | Prompt injection, deepfakes |

## Security Roles & Salaries (Global)

| Role | Focus |
|------|-------|
| Security Analyst (SOC) | Monitor alerts, respond |
| Penetration Tester | Authorized hacking |
| Security Engineer | Build secure systems |
| AppSec Engineer | Secure code & SDLC |
| GRC / Compliance | Policies, audits |
| CISO | Executive security leader |
