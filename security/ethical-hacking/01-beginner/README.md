# Beginner Guide — Ethical Hacking

**Read first:** Ethics and law — unauthorized hacking is **illegal**.

---

## Rules Before You Touch Any Tool

1. Only test **your own** machines or **official labs**
2. Bug bounty = read scope document 100%
3. Never test employer/client systems without **written permission**
4. Document everything for reports, not bragging

---

## Week 1: Lab Setup

| Day | Task |
|-----|------|
| 1 | Create TryHackMe free account |
| 2 | Install VirtualBox or VMware |
| 3 | Install Kali Linux VM (or use TryHackMe browser) |
| 4 | Complete TryHackMe "Intro to Offensive Security" |
| 5 | Install DVWA locally (Docker: `docker run -p 80:80 vulnerables/web-dvwa`) |
| 6 | Learn basic Linux: `ls`, `cd`, `grep`, `curl` |
| 7 | Write ethics pledge in your notes |

---

## Legal Practice Only

| OK | NOT OK |
|----|--------|
| TryHackMe rooms | Random website scanning |
| DVWA on localhost | School/work wifi without permission |
| HackerOne in-scope targets | "Testing" friend's Facebook |
| Your own VPS | Shodan → exploit random IPs |
