# Ethical Hacking

**Authorized** security testing — find vulnerabilities before criminals do.

> ⚠️ **LEGAL:** Only test systems you own, lab environments (DVWA, TryHackMe), or bug bounty programs with explicit scope. Unauthorized hacking is a crime worldwide.

---

## What Ethical Hackers Do

| Activity | Legal when… |
|----------|-------------|
| Reconnaissance | Target is yours or in-scope |
| Vulnerability scanning | Permission granted |
| Exploitation (PoC) | Written authorization |
| Reporting | Responsible disclosure to owner |
| Bug bounty | Program rules followed |

---

## Ethical Hacking Process (PTES)

```
1. Planning & scope agreement
2. Reconnaissance (passive + active)
3. Scanning (ports, services)
4. Vulnerability analysis
5. Exploitation (proof of concept)
6. Post-exploitation (limited, authorized)
7. Reporting & remediation advice
```
