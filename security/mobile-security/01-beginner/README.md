# Beginner Guide — Mobile (Phone) Security

**15-minute setup for Android or iPhone.**

---

## All Phones

1. **Update OS** — Settings → System/General → Software Update
2. **Strong lock** — 6+ digit PIN or passphrase (not pattern alone)
3. **Find My Device** — ON (Google or Apple)
4. **Review app permissions** — remove camera/mic/location from apps that don't need them
5. **Official app stores only**
6. **2FA** on Apple ID / Google account

---

## Android

Settings → Security → Google Play Protect → Scan

## iPhone

Settings → Face ID & Passcode → require passcode immediately

---

## If phone is lost

1. Use Find My to locate/lock/wipe
2. Change passwords for email, banking from another device
3. Report to carrier if needed
