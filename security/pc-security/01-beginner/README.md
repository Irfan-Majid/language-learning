# Beginner Guide — PC Security

**Do this week on your main computer.**

---

## Windows Checklist

- [ ] Windows Update → install all pending
- [ ] Windows Security → virus scan complete
- [ ] BitLocker or device encryption ON
- [ ] Standard user account for daily use (not Administrator)
- [ ] Firewall ON (default)
- [ ] Auto-lock after 5 minutes
- [ ] Browser: uBlock Origin, HTTPS-only mode

## Mac Checklist

- [ ] macOS updates installed
- [ ] FileVault encryption ON
- [ ] Firewall ON (System Settings → Network → Firewall)
- [ ] Gatekeeper enabled (default)

## Linux Checklist

- [ ] `sudo apt update && sudo apt upgrade`
- [ ] UFW: `sudo ufw enable`
- [ ] SSH: disable password auth, use keys only

---

## Developer extras

- [ ] `.env` in `.gitignore`
- [ ] Full disk encryption before traveling
- [ ] Password manager for all dev accounts
