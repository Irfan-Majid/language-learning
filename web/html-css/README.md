# HTML & CSS — Web Foundations

Every web developer needs HTML (structure) and CSS (style) before frameworks.

---

## Learning Path

| Week | Topic |
|------|-------|
| 1 | HTML tags, semantic elements, forms |
| 2 | CSS selectors, box model, flexbox |
| 3 | Responsive design, media queries |
| 4 | Build a landing page from scratch |

Then → [languages/javascript/](../languages/javascript/) → [frameworks/react/](../frameworks/react/)

## Checklist

- [ ] Semantic HTML (`header`, `main`, `footer`)
- [ ] Forms with labels and validation
- [ ] Flexbox layout
- [ ] CSS Grid basics
- [ ] Mobile-responsive page
- [ ] Accessibility basics (alt text, contrast)

---

*Do NOT skip HTML/CSS and jump straight to React — you will struggle with layout.*
